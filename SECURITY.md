# Security

## What the plugin does

CSV Table reads and rewrites the text of the buffer you run it on. It writes one small colour scheme file to `Packages/User/CSV Table/` and reads `CSV Table.sublime-settings`. It makes no network requests, runs no external programs and reads no other files.

## Reporting a vulnerability

Report it privately at https://github.com/MMSs/sublime-csv-table/security/advisories/new. Do not open a public issue.

Include the Sublime Text build, the plugin version, your OS, a file or steps that reproduce it, and what you expected.

Only the latest release is supported.
